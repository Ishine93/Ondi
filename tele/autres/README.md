# Ondi on other TVs and devices

Ondi has installable apps for **Samsung**, **LG**, **Android TV / Google TV** (Sony, Philips, TCL, Xiaomi, Nvidia Shield, Chromecast with Google TV, Google TV Streamer…) and **Amazon Fire TV**. For everything else, these options work.

**Always first:** the Ondi server must run on a Windows PC, a Mac or a mini-PC on the same network (https://github.com/Ishine93/Ondi). Its address is in Ondi → **Settings → Phone and TV** (e.g. `http://192.168.1.50:8097`).

| Device | Best way |
|---|---|
| TV with a web browser (Hisense VIDAA, Philips Saphi, Panasonic, older Samsung/LG…) | Open the browser, type the address, add it to favourites. Ondi switches to big-screen mode by itself. |
| Xbox | Microsoft Edge → type the address → pin it to Home. The controller works like a remote. |
| PlayStation 5 | No real browser: use another option. |
| Apple TV | No apps from outside the App Store and no browser: on an iPhone, iPad or Mac open Ondi in Safari, start a video and tap the **AirPlay** icon. |
| Roku | No browser and no sideloading of web apps: use a computer with HDMI, or a cheap Google TV / Fire TV stick. |
| Chromecast (old model, no remote) | No apps can be installed: from Chrome on a computer, menu ⋮ → **Cast…** → **Cast tab** (picture quality depends on the computer). The **Chromecast with Google TV** does install the Android TV app. |
| Any TV with HDMI | Plug a computer in and open the address in its browser (full screen with F11). |

**Phone:** open the address in the browser, then **Add to Home Screen** (Chrome: menu ⋮; Safari: Share button) to get an icon like an app.

**Need help?** Paste `PROMPT-IA.md` into an AI assistant.

# Ondi sur les autres télés et appareils

Ondi a des applis à installer pour **Samsung**, **LG**, **Android TV / Google TV** (Sony, Philips, TCL, Xiaomi, Nvidia Shield, Chromecast avec Google TV, Google TV Streamer…) et **Amazon Fire TV**. Pour tout le reste, ces solutions marchent.

**Toujours d'abord :** le serveur Ondi doit tourner sur un PC Windows, un Mac ou un mini-PC du même réseau (https://github.com/Ishine93/Ondi). Son adresse est dans Ondi → **Réglages → Téléphone et télé** (ex. `http://192.168.1.50:8097`).

| Appareil | La meilleure solution |
|---|---|
| Télé avec un navigateur web (Hisense VIDAA, Philips Saphi, Panasonic, anciennes Samsung/LG…) | Ouvre le navigateur, tape l'adresse, ajoute-la aux favoris. Ondi passe tout seul en affichage grand écran. |
| Xbox | Microsoft Edge → tape l'adresse → épingle-la à l'accueil. La manette sert de télécommande. |
| PlayStation 5 | Pas de vrai navigateur : prends une autre solution. |
| Apple TV | Pas d'appli hors App Store ni de navigateur : sur iPhone, iPad ou Mac, ouvre Ondi dans Safari, lance une vidéo et touche l'icône **AirPlay**. |
| Roku | Ni navigateur ni installation d'appli web : un ordinateur en HDMI, ou une clé Google TV / Fire TV pas chère. |
| Chromecast (ancien modèle sans télécommande) | Impossible d'y installer une appli : depuis Chrome sur un ordinateur, menu ⋮ → **Caster…** → **Caster l'onglet** (qualité selon l'ordinateur). La **Chromecast avec Google TV**, elle, installe l'appli Android TV. |
| N'importe quelle télé avec HDMI | Branche un ordinateur et ouvre l'adresse dans son navigateur (plein écran avec F11). |

**Téléphone :** ouvre l'adresse dans le navigateur, puis **Ajouter à l'écran d'accueil** (Chrome : menu ⋮ ; Safari : bouton Partager) pour avoir une icône comme une appli.

**Besoin d'aide ?** Colle `PROMPT-IA.md` dans un assistant IA.
