I want to install a self-made app called **Ondi** on my **Samsung Smart TV (Tizen)** and I need step-by-step help, one step at a time, waiting for my answer before moving on.

- I have a zip with: `Ondi.wgt` (an **unsigned** Tizen web app), `installer-apps2samsung.bat` / `.command` (installs the free community tool **Apps2Samsung**), and a README.

Please start by asking me: my exact TV model (shown in Settings → Support → About This TV), whether my remote has number keys, and whether my computer is Windows or Mac. Then guide me, explain any error message I paste, and keep the language simple.

# Prompt d'aide IA — télé Samsung

Copie tout ce qui est entre les traits et colle-le dans un assistant IA (ChatGPT, Claude, Gemini…).

---

Je veux installer une appli maison appelée **Ondi** sur ma **télé Samsung (Tizen)** et j'ai besoin d'aide pas à pas, une étape à la fois, en attendant ma réponse avant de continuer.

Contexte :
- Ondi est un serveur multimédia déjà installé sur mon ordinateur (PC Windows, Mac ou mini-PC), sur le même réseau que la télé. L'appli télé trouve seulement ce serveur et affiche son interface web en plein écran.
- J'ai un zip avec : `Ondi.wgt` (appli web Tizen **non signée**), `installer-apps2samsung.bat` / `.command` (installe l'outil gratuit **Apps2Samsung**) et un README.
- La méthode prévue : activer le **mode développeur** sur la télé (Applications → taper 12345 ; télés 2025–2026 : Applications → Paramètres des applications), entrer l'adresse IP de mon ordinateur, redémarrer la télé ; puis dans Apps2Samsung choisir ma télé et installer mon propre fichier (« Install a file… » ou « Custom WGT ») ; Apps2Samsung le signe avec le certificat de mon compte Samsung.
- L'adresse de l'ordinateur est affichée dans Ondi → Réglages → Téléphone et télé (ex. 192.168.1.50:8097).

Commence par me demander : le modèle exact de ma télé (Paramètres → Assistance → À propos de ce téléviseur), si ma télécommande a des touches chiffrées, et si mon ordinateur est un Windows ou un Mac. Ensuite guide-moi, explique les messages d'erreur que je te colle, et reste simple.
