## English
- TV apps now carry the Débrideur version number (2.0.2 instead of 1.0.0), so you can see at a glance which one is installed.
- A TV with an older Débrideur app shows a message offering to reinstall it. From now on, a TV app only changes number when the app itself changes.
- Complete release page: what's new, which file to download, and step-by-step installation for every device.
- The update window no longer shows Markdown symbols.

## Français
- Les applis télé portent maintenant le numéro du Débrideur (2.0.2 au lieu de 1.0.0) : on voit d'un coup d'œil laquelle est installée.
- Une télé qui a une ancienne appli Débrideur affiche un message pour proposer de la réinstaller. Désormais, une appli télé ne change de numéro que quand l'appli elle-même change.
- Page de version complète : nouveautés, quel fichier télécharger et installation pas à pas pour chaque appareil.
- La fenêtre de mise à jour n'affiche plus les symboles Markdown.
